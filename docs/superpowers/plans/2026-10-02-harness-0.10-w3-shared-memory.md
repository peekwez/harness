# W3 Shared Memory Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace harness-managed working and durable memory with one committed, human-curated shared memory folder, `.claude/memory/shared/`, and remove every engine path that wrote or read `.harness/memory/`.

**Architecture:** A new library, `engine/shared_memory.py`, owns the shared folder: promotion, the index, the personal-memory lookup, and the `CLAUDE.md` import. The CLI exposes it as `harness memory promote|changed`. A new built-in gate, G10, blocks agent writes into the folder at `pre_change`, so every host adapter inherits the guard. The permit layer answers `ask` for every promotion. `engine/memory.py` and all its consumers go: close, adjudicate, review precedents, resolver leftovers, init, and the PreCompact flush. PreCompact now calls `harness precompact`. Four upgrade steps in `engine/upgrade_w3.py` migrate existing repos.

**Tech Stack:** Python 3 (stdlib, PyYAML already an engine dependency), pytest, git CLI, Claude Code hook JSON.

**Spec:** `docs/superpowers/specs/2026-10-02-harness-0.10-design.md` (section 8, D-0.10-02, section 12 steps 3, 6, 13). Index: `docs/superpowers/plans/2026-10-02-harness-0.10-index.md`.

## Global Constraints

- Folder: `.claude/memory/shared/`, committed. It holds `MEMORY.md` and one file per fact.
- The `CLAUDE.md` template imports `@.claude/memory/shared/MEMORY.md`.
- `harness memory promote <file> | --text "<fact>"` adds front matter `promoted_by` (git identity) and `promoted_at`, and one line in `shared/MEMORY.md` of 120 characters or fewer.
- A PreToolUse rule blocks agent Write and Edit calls into `.claude/memory/shared/`. The message names `harness memory promote`.
- The permit layer never auto-approves `harness memory promote`. A human approves each promotion.
- At close, the close-slice skill lists personal memory files changed since the slice started and asks: "Promote any to shared?"
- `doctor` warns when `shared/MEMORY.md` has more than 40 entries.
- Personal agent memory stays with Claude Code. Harness never writes it (spec section 15: out of scope).
- Remove `engine/memory.py`, `.harness/memory/`, `harness memory write|flush|compact`.
- Upgrade: export `.harness/memory/durable.jsonl` rows to `.harness/cache/durable-memory-export.md` for human review (never promote), then delete `.harness/memory/`. Each step that deletes files asks first. Each step is idempotent.
- Upgrade: add the import to `CLAUDE.md` when it carries the harness marker; otherwise print the line and do not edit the file. Create `.claude/memory/shared/MEMORY.md` when it does not exist.
- Finding messages and CLI output follow STE-80: rule, what is wrong, file; 25 words or fewer; then the fix. Until W4 lands, the fix goes at the end of `message` after `Fix:`.
- Gate IDs never change or get reused. G2, G4, G7, G8 are retired; G9 belongs to W6.
- Tests use `tests/conftest.py` (`build_toy_repo`, `run_cli`, `git`). Run with `python3 -m pytest tests/ -q`. Delete tests of removed features in the same task.
- `engine/cli/*.py` modules stay at 500 lines or fewer (`tests/engine/test_cli_split.py`).
- Commit messages end with `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.
- Stay inside W3 ownership. The one exception: Task 2 adds the token `` `precompact` `` to README's subcommand list, because `test_readme_documents_every_cli_subcommand` requires it. W7 rewrites README later.

## Review Focus

1. A human runs `harness memory promote` twice on the same file (for example, from the upgrade export file): expect no error, no second index line, and `"promoted": false, "reason": "already shared"`. Pinned in Task 1.
2. A machine with no git `user.name` (CI, fresh container) runs promote: expect exit 1 with a fix line, and no file written in `shared/`. Pinned in Task 1 and, for upgrade, in Task 11.
3. A very long fact or file name: expect the index line to stay at 120 characters or fewer and to keep a valid `[title](slug.md)` link. Pinned in Task 1.
4. An agent writes the shared folder through a path variant: absolute path, `docs/../`, different letter case (macOS is case-insensitive), or a slice worktree prefix. Expect a G10 block for each. Pinned in Tasks 1 and 6.
5. A promotion command in a form the permit layer did not expect: `--root` before the subcommand, `python3 .../bin/harness`, a `bash -c` wrapper, or no bound slice. Expect `ask`, never `allow`. Pinned in Task 7.

"""Shared memory (D-0.10-02): team facts that a human promoted.

Harness manages only `.claude/memory/shared/`. Personal agent memory stays
with the host (Claude Code auto memory). Harness reads its location only to
list the files that changed during a slice, so a human can promote them.
"""
from __future__ import annotations

import json
import os
import posixpath
import re
import subprocess
from pathlib import Path

from . import HarnessError, get_slice, now_iso

SHARED_DIR = ".claude/memory/shared"
INDEX_NAME = "MEMORY.md"
INDEX_REL = f"{SHARED_DIR}/{INDEX_NAME}"
CLAUDE_IMPORT = "@.claude/memory/shared/MEMORY.md"
CLAUDE_MARKER = "harness-enforced"
MAX_INDEX_LINE = 120
MAX_SLUG = 50
ENTRY_WARN_LIMIT = 40
INDEX_HEADER = (
    "# Shared memory\n\n"
    "Team facts. A human adds each one with `harness memory promote`.\n"
    "Agents read this file. Agents do not edit it.\n\n")
_SHARED_SEGMENT = "/" + SHARED_DIR.casefold() + "/"


# ------------------------------------------------------------------ paths
def in_shared_dir(rel: str) -> bool:
    """True when a repo-relative path is in, or is, the shared folder.

    Case-insensitive (macOS file systems are), traversal-normalized, and
    matched anywhere in the path so a slice worktree prefix still counts.
    Absolute paths are outside the repo after event normalization.
    """
    path = str(rel).replace("\\", "/")
    if path.startswith("/"):
        return False
    norm = "/" + posixpath.normpath(path).casefold() + "/"
    return _SHARED_SEGMENT in norm


# ------------------------------------------------------------------ index
def ensure_index(root) -> bool:
    """Create `shared/MEMORY.md` with its header. True when it was created."""
    index = Path(root) / INDEX_REL
    if index.exists():
        return False
    index.parent.mkdir(parents=True, exist_ok=True)
    index.write_text(INDEX_HEADER, encoding="utf-8")
    return True


def index_entries(root) -> list:
    """The `- [title](file.md) — summary` lines of the shared index."""
    index = Path(root) / INDEX_REL
    if not index.exists():
        return []
    return [line for line in index.read_text(encoding="utf-8").splitlines()
            if line.startswith("- [")]


def slugify(text: str) -> str:
    """File-name slug: lowercase ASCII words joined by `-`, 50 chars max."""
    slug = re.sub(r"[^a-z0-9]+", "-", str(text).lower()).strip("-")
    if len(slug) > MAX_SLUG:
        cut = slug[:MAX_SLUG]
        slug = (cut.rsplit("-", 1)[0] if "-" in cut else cut).strip("-")
    return slug or "fact"


def _one_line(text: str) -> str:
    return " ".join(str(text).split())


def _first_line(body: str) -> str:
    for line in body.splitlines():
        line = line.strip().lstrip("#").strip()
        if line.startswith(("- ", "* ")):
            line = line[2:].strip()
        if line:
            return line
    return ""


def index_line(title: str, slug: str, summary: str) -> str:
    """One index line of MAX_INDEX_LINE characters or fewer.

    The link part stays whole: the title is cut first (to keep the link
    within 80 characters), then the summary.
    """
    title = _one_line(title).replace("[", "(").replace("]", ")")
    frame = len(f"- []({slug}.md)")
    if frame + len(title) > 80:
        title = title[:max(1, 80 - frame - 1)].rstrip() + "…"
    head = f"- [{title}]({slug}.md)"
    summary = _one_line(summary)
    line = f"{head} — {summary}" if summary else head
    if len(line) > MAX_INDEX_LINE:
        line = line[:MAX_INDEX_LINE - 1].rstrip() + "…"
    return line


def _add_index_line(root, line: str, slug: str) -> bool:
    ensure_index(root)
    index = Path(root) / INDEX_REL
    text = index.read_text(encoding="utf-8")
    if f"]({slug}.md)" in text:
        return False
    if text and not text.endswith("\n"):
        text += "\n"
    index.write_text(text + line + "\n", encoding="utf-8")
    return True


# ------------------------------------------------------------------ facts
def split_front_matter(text: str) -> tuple:
    """`(meta, body)`. Text without valid YAML front matter -> `({}, text)`."""
    if text.startswith("---\n"):
        end = text.find("\n---", 4)
        if end != -1:
            import yaml
            try:
                meta = yaml.safe_load(text[4:end]) or {}
            except yaml.YAMLError:
                meta = None
            if isinstance(meta, dict):
                return meta, text[end + 4:].lstrip("\n")
    return {}, text


def _render_fact(meta: dict, body: str) -> str:
    import yaml
    front = yaml.safe_dump(meta, sort_keys=False, allow_unicode=True,
                           width=1000)
    return f"---\n{front}---\n\n{body.strip()}\n"


def git_identity(root) -> str:
    """`Name <email>` from git config. Fails when `user.name` is not set."""
    def cfg(key):
        proc = subprocess.run(["git", "-C", str(root), "config", key],
                              capture_output=True, text=True)
        return proc.stdout.strip() if proc.returncode == 0 else ""
    name, email = cfg("user.name"), cfg("user.email")
    if not name:
        raise HarnessError(
            "memory promote: git user.name is not set. "
            "Fix: git config user.name \"<your name>\".")
    return f"{name} <{email}>" if email else name


def promote(root, *, source=None, text=None, name=None) -> dict:
    """Copy one fact into the shared folder and index it.

    Args:
        root: Substrate root.
        source: A memory file (front matter optional). Mutually exclusive
            with `text`.
        text: The fact itself.
        name: File-name override (slugified).

    Returns:
        `{"promoted": True, "path", "promoted_by", "promoted_at",
        "index_line", "entries"}`, or `{"promoted": False, "reason":
        "already shared", "path", "index_line_added"}` when the same fact
        is already in the folder.

    Raises:
        HarnessError: no fact, two facts, an empty fact, an index file, a
            missing file, no git identity, or a different fact already
            under the same name.
    """
    root = Path(root)
    if (source is None) == (text is None):
        raise HarnessError(
            "memory promote: pass one fact. Fix: give a file or --text \"<fact>\".")
    meta, body = {}, ""
    if source is not None:
        source = Path(source).expanduser().resolve()
        if not source.is_file():
            raise HarnessError(
                f"memory promote: file not found: {source}. "
                f"Fix: pass the path of one memory file.")
        if source.name == INDEX_NAME:
            raise HarnessError(
                f"memory promote: {source.name} is an index, not a fact. "
                f"Fix: promote one fact file.")
        meta, body = split_front_matter(source.read_text(encoding="utf-8"))
    else:
        body = text
    body = body.strip()
    if not body:
        raise HarnessError(
            "memory promote: the fact is empty. Fix: give a fact with text.")

    words = body.split()
    title = (_one_line(meta.get("name") or "")
             or (source.stem if source is not None else " ".join(words[:8])))
    summary = _one_line(meta.get("description") or "") or _first_line(body)
    slug = slugify(name or meta.get("name")
                   or (source.stem if source is not None
                       else " ".join(words[:6])))
    identity = git_identity(root)          # before any write
    rel = f"{SHARED_DIR}/{slug}.md"
    target = root / rel
    line = index_line(title, slug, summary)

    if target.exists():
        _old, old_body = split_front_matter(target.read_text(encoding="utf-8"))
        if old_body.strip() != body:
            raise HarnessError(
                f"memory promote: {rel} exists with other text. "
                f"Fix: pass --name <new-name>.")
        return {"promoted": False, "reason": "already shared", "path": rel,
                "index_line_added": _add_index_line(root, line, slug)}

    front = {k: v for k, v in meta.items()
             if k not in ("name", "description", "promoted_by", "promoted_at")}
    front = {"name": title, "description": summary, **front,
             "promoted_by": identity, "promoted_at": now_iso()}
    target.parent.mkdir(parents=True, exist_ok=True)
    ensure_index(root)
    target.write_text(_render_fact(front, body), encoding="utf-8")
    _add_index_line(root, line, slug)
    return {"promoted": True, "path": rel, "promoted_by": identity,
            "promoted_at": front["promoted_at"], "index_line": line,
            "entries": len(index_entries(root))}

def main_repo_root(root) -> Path:
    """The main worktree's root. Linked worktrees share one personal memory."""
    proc = subprocess.run(
        ["git", "-C", str(root), "rev-parse", "--path-format=absolute",
         "--git-common-dir"], capture_output=True, text=True)
    if proc.returncode == 0 and proc.stdout.strip():
        common = Path(proc.stdout.strip())
        if common.name == ".git":
            return common.parent.resolve()
    return Path(root).resolve()


def project_slug(path) -> str:
    """Claude Code's project folder name: each non-alphanumeric char -> `-`."""
    return re.sub(r"[^A-Za-z0-9]", "-", str(path))


def _setting(path: Path, key: str):
    try:
        data = json.loads(path.read_text(encoding="utf-8"))
    except (OSError, ValueError):
        return None
    value = data.get(key) if isinstance(data, dict) else None
    return value if isinstance(value, str) and value.strip() else None


def personal_memory_dir(root) -> Path:
    """Where Claude Code keeps this project's personal (auto) memory.

    1. `autoMemoryDirectory` in `.claude/settings.local.json`, then in the
       user settings (`$CLAUDE_CONFIG_DIR` or `~/.claude`)/settings.json.
       Project `.claude/settings.json` is not read: Claude Code does not
       accept the key there.
    2. Else `<config dir>/projects/<slug>/memory`, where the slug is the
       main repo path with each non-alphanumeric character replaced by `-`.
    """
    root = Path(root)
    config_dir = Path(os.environ.get("CLAUDE_CONFIG_DIR")
                      or Path.home() / ".claude")
    for settings in (root / ".claude" / "settings.local.json",
                     config_dir / "settings.json"):
        value = _setting(settings, "autoMemoryDirectory")
        if value:
            path = Path(os.path.expanduser(value))
            return path if path.is_absolute() else root / path
    return config_dir / "projects" / project_slug(main_repo_root(root)) / "memory"


def changed_since(directory, since: float) -> list:
    """Memory files (`*.md`, not the index) modified at or after `since`."""
    directory = Path(directory)
    if not directory.is_dir():
        return []
    return sorted(str(p) for p in directory.rglob("*.md")
                  if p.is_file() and p.name != INDEX_NAME
                  and p.stat().st_mtime >= since)


def slice_started_epoch(root, slice_id: str) -> int:
    """Commit time of the slice's `started_at_commit`: a lower bound on the
    slice start, so the changed-file list never misses a file."""
    base = get_slice(root, slice_id).get("started_at_commit")
    if not base:
        raise HarnessError(
            f"memory changed: slice {slice_id} has no started_at_commit. "
            f"Fix: pass --since <ISO time>.")
    proc = subprocess.run(["git", "-C", str(root), "show", "-s",
                           "--format=%ct", base], capture_output=True, text=True)
    out = proc.stdout.strip()
    if proc.returncode != 0 or not out.isdigit():
        raise HarnessError(
            f"memory changed: commit {base[:12]} not found. "
            f"Fix: pass --since <ISO time>.")
    return int(out)

def claude_md_state(root) -> str:
    """`missing`, `current` (has the import), `marked` (harness file without
    the import) or `unmarked` (someone else's file without the import)."""
    path = Path(root) / "CLAUDE.md"
    if not path.exists():
        return "missing"
    text = path.read_text(encoding="utf-8")
    if any(line.strip() == CLAUDE_IMPORT for line in text.splitlines()):
        return "current"
    return "marked" if CLAUDE_MARKER in text.casefold() else "unmarked"


def add_claude_import(root) -> bool:
    """Append the import to a harness-marked CLAUDE.md. True when written."""
    if claude_md_state(root) != "marked":
        return False
    path = Path(root) / "CLAUDE.md"
    text = path.read_text(encoding="utf-8").rstrip("\n")
    path.write_text(f"{text}\n{CLAUDE_IMPORT}\n", encoding="utf-8")
    return True

# ------------------------------------------------------------------ doctor
def shared_memory_health(root) -> dict:
    """Advisory health of the shared folder for `doctor --substrate`."""
    root = Path(root)
    entries = len(index_entries(root))
    warnings = []
    if not (root / INDEX_REL).exists():
        warnings.append(f"Shared memory index is missing: {INDEX_REL}. "
                        f"Fix: run harness upgrade.")
    elif (root / ".git").exists() and subprocess.run(
            ["git", "-C", str(root), "check-ignore", "-q", INDEX_REL],
            capture_output=True).returncode == 0:
        warnings.append(f"Git ignores {INDEX_REL}, so the team cannot share "
                        f"it. Fix: remove the ignore rule.")
    if entries > ENTRY_WARN_LIMIT:
        warnings.append(f"Shared memory has {entries} entries; the limit is "
                        f"{ENTRY_WARN_LIMIT}. File: {INDEX_REL}. "
                        f"Fix: merge or remove old entries.")
    return {"entries": entries, "limit": ENTRY_WARN_LIMIT,
            "warnings": warnings}

Design notes:
- Only `attempt` and `adjudication` rows are offered. They were the rows 0.9 kept on purpose. Close-summary `observation` rows ("slice X: N working-memory entries") are noise and stay in git history.
- An interrupted close left its journal in `.harness/memory/session/.close-<key>.json`. The step moves it to `.harness/cache/close-<key>.json` (Task 5's new path) before any delete, so recovery still works.
- A failed promotion (for example, no git identity) keeps `.harness/memory/` so the human can fix the cause and run upgrade again.
- The `.gitignore` line goes only after `.harness/memory/` is gone, so declined deletes never surface session files to git.
- An unmarked `CLAUDE.md` is never edited. It produces a `check:` line through `advise` (W1 framework), printed on every run but never pending, so a second run reports "already on 0.10".
- Upgrade never promotes. Promotion is a human choice (spec section 8), and `--yes` cannot tell questions apart. The step exports `attempt` and `adjudication` rows to `.harness/cache/durable-memory-export.md`, each with a ready `harness memory promote --text` command, and `advise` points to it until the human deletes the file.

"""W3 upgrade steps (spec section 12, steps 3, 6, 13; D-0.10-02).

Retire `.harness/memory/` after exporting its durable rows for review,
drop its git lines, scaffold `.claude/memory/shared/MEMORY.md`, and add the
shared-memory import to a harness-marked CLAUDE.md.
"""
from __future__ import annotations

import shlex
import shutil
import subprocess
from pathlib import Path

from engine import read_jsonl
from engine.shared_memory import (CLAUDE_IMPORT, INDEX_REL, add_claude_import,
                                  claude_md_state, ensure_index)
from engine.upgrade_010 import Ask, Step, register

MEMORY_DIR = Path(".harness") / "memory"
LEGACY_ATTR = ".harness/memory/durable.jsonl merge=union"
LEGACY_IGNORE = ".harness/memory/session/"
OFFERED_KINDS = ("attempt", "adjudication")


# ------------------------------------------------- retire .harness/memory/
def _offered(root: Path) -> list:
    rows = read_jsonl(root / MEMORY_DIR / "durable.jsonl")
    return [r for r in rows if r.get("kind") in OFFERED_KINDS
            and str(r.get("content") or "").strip()]


def _journals(root: Path) -> list:
    session = root / MEMORY_DIR / "session"
    return sorted(session.glob(".close-*.json")) if session.is_dir() else []


def _fact_text(row: dict) -> str:
    text = " ".join(str(row.get("content", "")).split())
    attempt = row.get("attempt") or {}
    if row.get("kind") == "attempt" and attempt:
        text += (f" Approach: {attempt.get('approach')}."
                 f" Outcome: {attempt.get('outcome')}."
                 f" Why: {attempt.get('why')}.")
    return text


def describe_retire(root) -> list:
    root = Path(root)
    if not (root / MEMORY_DIR).exists():
        return []
    lines = []
    offered = _offered(root)
    if offered:
        lines.append(f"export {len(offered)} durable memory rows to "
                     f"{EXPORT_REL} for human review")
    journals = _journals(root)
    if journals:
        lines.append(f"move {len(journals)} interrupted close journals to "
                     f".harness/cache/")
    lines.append("delete .harness/memory/ (git history keeps it)")
    return lines


EXPORT_REL = ".harness/cache/durable-memory-export.md"


def _write_export(root: Path, rows: list) -> Path:
    """Write offered rows as review notes with a ready promote command each.

    Upgrade never promotes: a promotion is a human choice (spec section 8).
    """
    path = root / EXPORT_REL
    path.parent.mkdir(parents=True, exist_ok=True)
    out = ["# Durable memory from harness 0.9", "",
           "Review each fact. To share one with the team, run its command.",
           "Delete this file when you are done.", ""]
    for row in rows:
        text = _fact_text(row)
        out += [f"## {row.get('id')}", "", text, "",
                "```bash", f"harness memory promote --text {shlex.quote(text)}",
                "```", ""]
    path.write_text("\n".join(out))
    return path


def apply_retire(root, ask: Ask) -> list:
    root = Path(root)
    if not (root / MEMORY_DIR).exists():
        return []
    report = []
    offered = _offered(root)
    if offered:
        _write_export(root, offered)
        report.append(f"exported {len(offered)} rows to {EXPORT_REL}")
    for journal in _journals(root):
        cache = root / ".harness" / "cache"
        cache.mkdir(parents=True, exist_ok=True)
        journal.replace(cache / journal.name.lstrip("."))
        report.append(f"moved {journal.name} to .harness/cache/")
    if not ask("Delete .harness/memory/? Git history keeps it, and "
               f"{EXPORT_REL} holds the facts to review."):
        report.append("skipped: needs confirmation")
        return report
    if (root / ".git").exists():
        subprocess.run(["git", "-C", str(root), "rm", "-r", "-q", "--cached",
                        "--ignore-unmatch", "--", ".harness/memory"],
                       capture_output=True, text=True)
    shutil.rmtree(root / MEMORY_DIR)
    report.append("deleted .harness/memory/")
    return report


def advise_retire(root) -> list:
    if not (Path(root) / EXPORT_REL).exists():
        return []
    return [f"check: review {EXPORT_REL}. Promote facts with the commands "
            f"in it, then delete the file."]


# ------------------------------------------------------------- git lines
def _lines(path: Path) -> list:
    return path.read_text().splitlines() if path.exists() else []


def _pending_git_lines(root: Path) -> list:
    pending = []
    if LEGACY_ATTR in _lines(root / ".gitattributes"):
        pending.append((".gitattributes", LEGACY_ATTR))
    # keep the ignore line while session files may still exist
    if (not (root / MEMORY_DIR).exists()
            and LEGACY_IGNORE in _lines(root / ".gitignore")):
        pending.append((".gitignore", LEGACY_IGNORE))
    return pending


def describe_git_lines(root) -> list:
    return [f"remove '{entry}' from {name}"
            for name, entry in _pending_git_lines(Path(root))]


def apply_git_lines(root, ask: Ask) -> list:
    root = Path(root)
    report = []
    for name, entry in _pending_git_lines(root):
        path = root / name
        kept = [line for line in _lines(path) if line != entry]
        path.write_text("\n".join(kept) + "\n")
        report.append(f"removed '{entry}' from {name}")
    return report


# ---------------------------------------------------------- shared index
def describe_index(root) -> list:
    return [] if (Path(root) / INDEX_REL).exists() else [f"create {INDEX_REL}"]


def apply_index(root, ask: Ask) -> list:
    return [f"created {INDEX_REL}"] if ensure_index(root) else []


# ------------------------------------------------------------- CLAUDE.md
_CLAUDE_LINES = {
    "missing": ["create CLAUDE.md from the harness template"],
    "marked": [f"add {CLAUDE_IMPORT} to CLAUDE.md"],
    "unmarked": [],          # not ours to edit: see advise_claude
    "current": [],
}


def describe_claude(root) -> list:
    return list(_CLAUDE_LINES[claude_md_state(root)])


def advise_claude(root) -> list:
    if claude_md_state(root) != "unmarked":
        return []
    return [f"check: CLAUDE.md has no harness marker. Add this line by "
            f"hand: {CLAUDE_IMPORT}"]


def apply_claude(root, ask: Ask) -> list:
    root = Path(root)
    state = claude_md_state(root)
    if state == "missing":
        from engine.cli.common import PLUGIN_ROOT
        shutil.copy(PLUGIN_ROOT / "templates" / "claude-md.md",
                    root / "CLAUDE.md")
        return ["created CLAUDE.md from the harness template"]
    if state == "marked":
        add_claude_import(root)
        return [f"added {CLAUDE_IMPORT} to CLAUDE.md"]
    return []


register(Step(id="w3.retire-durable-memory",
              title="Export durable memory rows for review, then delete "
                    ".harness/memory/.",
              describe=describe_retire, apply=apply_retire, destructive=True,
              advise=advise_retire))
register(Step(id="w3.memory-git-lines",
              title="Remove .harness/memory/ lines from .gitattributes and "
                    ".gitignore.",
              describe=describe_git_lines, apply=apply_git_lines))
register(Step(id="w3.shared-memory-index",
              title="Create .claude/memory/shared/MEMORY.md.",
              describe=describe_index, apply=apply_index))
register(Step(id="w3.claude-md-import",
              title="Add the shared memory import to CLAUDE.md.",
              describe=describe_claude, apply=apply_claude,
              advise=advise_claude))
```
